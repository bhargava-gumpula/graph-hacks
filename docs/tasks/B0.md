# B0: Setup (S1 monorepo scaffold, S2 docker + env + worktree helper, S4 rules check)

- **Goal:** an empty but working TypeScript monorepo (npm workspaces, vitest, eslint, typecheck) and a FalkorDB container started by `docker compose`, so every later bundle (B1–B3) can start in its own worktree on a fixed, file-disjoint layout. Serves the §17.8 goal by making FalkorDB the one store from minute one.
- **Model:** Grok 4.7 for S1 + S2; the main chat (Opus 5.5) does S4 and the review gate.
- **Branch:** `hack/B0`. Worktree: no (runs in the main folder).
- **Read first:** PLAN §17, §2 "Tech stack", §6 "Repo layout" and "P0 tasks".

## Steps
### S1 Monorepo scaffold
1. Root `package.json`: `"private": true`, `"type": "module"`, `"engines": {"node": ">=22"}`, `"workspaces": ["packages/*", "apps/*"]`.
   Scripts:
   - `test`: `vitest run`
   - `typecheck`: `npm run typecheck --workspaces --if-present`
   - `build`: `npm run build --workspaces --if-present`
   - `dev`: `npm run dev --workspaces --if-present`
   - `lint`: `eslint .`
   - `db:up`: `docker compose up -d`
   - `db:ping`: `docker compose exec falkordb redis-cli GRAPH.QUERY sb_ping "RETURN 1"`
2. Root dev dependencies only: `typescript@^5`, `vitest`, `@types/node@^22`, `eslint`, `@eslint/js`, `typescript-eslint`. Nothing else (no falkordb client yet; that is M2 in B3).
3. `tsconfig.base.json`: `strict`, `target ES2023`, `module NodeNext`, `moduleResolution NodeNext`, `esModuleInterop`, `skipLibCheck`, `declaration`, `sourceMap`, `verbatimModuleSyntax`. Root `tsconfig.json` extends it with `noEmit` and includes `*.config.ts` (so eslint/vitest config is typechecked if needed).
4. Each workspace (`packages/core`, `packages/mcp`, `packages/cli`, `apps/server`, `apps/web`):
   - `package.json`: name `@switchboard/<dir>`, `"private": true`, `"type": "module"`, `"main": "src/index.ts"`, scripts `typecheck: tsc --noEmit -p tsconfig.json` and `build: tsc -p tsconfig.json`.
   - `tsconfig.json`: extends `../../tsconfig.base.json`, `rootDir: src`, `outDir: dist`, includes `src`, excludes `src/**/*.test.ts` from the build.
   - `src/index.ts`: a one-line placeholder export. Core exports `export const SWITCHBOARD_VERSION = "0.0.0";`.
   - `apps/web` stays a plain TS placeholder; Vite/React arrive in M10.
5. `packages/core/src/index.test.ts`: one vitest test that imports `SWITCHBOARD_VERSION` and asserts it is a string.
6. `vitest.config.ts`: include `packages/*/src/**/*.test.ts` and `apps/*/src/**/*.test.ts`.
7. `eslint.config.js` (flat config): `@eslint/js` recommended + `typescript-eslint` recommended; ignore `**/dist/**`, `**/node_modules/**`, `demo-repo/**`, `docs/**`.
8. Run `npm install` to create `package-lock.json`.

### S2 Docker, env, worktree helper
1. `docker-compose.yml`: one service `falkordb`, image `falkordb/falkordb:latest`, `container_name: switchboard-falkordb`, ports `6379:6379` and `3000:3000`, named volume `falkordb-data` mounted at `/var/lib/falkordb/data`, `restart: unless-stopped`.
2. `.env.example` (placeholders only):
   ```
   FALKORDB_URL=redis://localhost:6379
   SB_GRAPH=sb_demo
   SERVER_PORT=8787
   WEB_PORT=5173
   # Optional (F20 briefing summary). Leave empty to disable.
   ANTHROPIC_API_KEY=
   ```
3. `.gitignore`: `node_modules/`, `dist/`, `.env`, `.env.*` but not `.env.example`, `coverage/`, `*.log`, `.DS_Store`, `.vite/`, `bench/runs/`.
4. `scripts/wt.sh` (bash, `set -euo pipefail`, executable):
   - `wt.sh new <id>`: `git worktree add ../gh-<id> -b hack/<id> main`; copy `.env` into it if present; run `npm install` there; print `export SB_GRAPH=sb_<id>` as the next step.
   - `wt.sh rm <id>`: `git worktree remove ../gh-<id>` then `git branch -d hack/<id>`.
   - Anything else prints usage and exits 1.
