# B4: Parser + loader (M3, M4)

- **Goal:** parse a TS/JS repo into `File` nodes and `IMPORTS` edges in FalkorDB, idempotently. This is the dependency graph that every claim is checked against (PLAN §1, F1), so the graph is built from real code, not hand-declared scopes.
- **Model:** Opus 5.5 (main chat)
- **Branch:** `hack/B4`. Worktree: no
- **Read first:** PLAN §3 (File, IMPORTS), §6 M3 and M4; `demo-repo/expected.json`.

## Steps
1. `parseRepo(root)` loads a ts-morph `Project` from `<root>/tsconfig.json`, so path aliases resolve the way `tsc` resolves them. It skips `node_modules`, `.d.ts` and files outside `root`, and returns `{ files: [{path, lang, loc, hash}], imports: [{from, to, specifiers, typeOnly}] }` with repo-relative POSIX paths. Both `import … from` and `export … from` count as imports. There is one edge per (from, to) pair: specifiers are merged, and `typeOnly` is true only if every import of that pair is type-only.
2. `loadParse(g, parsed)` makes three write passes, in batches of 500: (a) `UNWIND … MERGE (f:File {path}) SET lang, loc, hash`; (b) delete the outgoing `IMPORTS` edges of the files being loaded, so a re-parse drops imports that were removed; (c) `UNWIND … MATCH from, to MERGE (a)-[r:IMPORTS]->(b) SET r.specifiers, r.typeOnly`. It records one `parse` summary event (via `recordEvent`, kind added to `EventKind`).
3. `scripts/parse.ts <dir>` → `connect()`, `ensureSchema`, `parseRepo`, `loadParse`; prints the counts. `npm run parse -- demo-repo`.

## Acceptance criteria
- [ ] Parsing `demo-repo` matches `expected.json`: 35 files, 51 imports, 3 type-only; `lib/utils.ts` imported by 20 files; the chain edges exist; the alias imports resolve to `lib/`; nothing imports `ui/AboutPage.tsx`
- [ ] Loading twice gives the same node and edge counts (idempotent), and removing an import and reloading drops that edge
- [ ] A Cypher check in the graph: `MATCH p=(:File {path:'ui/LoginForm.tsx'})-[:IMPORTS*3]->(:File {path:'lib/crypto.ts'}) RETURN count(p)` ≥ 1
- [ ] `npm test`, `npm run typecheck` and `npm run lint` green
