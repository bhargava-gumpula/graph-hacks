# B5: Conflict query (M5, Q1), the hero

- **Goal:** `claim(agent, paths)` checks the request against other agents' active claims through the parsed dependency graph and returns OK (and writes the claim) or CONFLICT with the exact import path. This is the one graph-native move from PLAN §1.
- **Model:** Opus 5.5 (main chat)
- **Branch:** `hack/B5`. Worktree: no
- **Read first:** PLAN §4 Q1, §3 (CLAIMS, WORKS_ON), DEVLOG B1 (`shortestPath` only works in WITH/RETURN).

## Rules (from Q1)
- A conflict is an active claim (`until > now`) by **another** agent on a file `g` where: `g` is the requested file `f` (SAME, hop 0); or `f -[:IMPORTS*1..k]-> g` (UPSTREAM: I depend on what they're changing); or `g -[:IMPORTS*1..k]-> f` (DOWNSTREAM: they depend on what I'm changing).
- Multi-hop paths that touch a hub file anywhere, ends included, are ignored. Hop 0 always counts.
- Return the shortest path per (requested file, other agent). `k` defaults to 3, capped at 4.
- No conflict → MERGE the claims (`since, until, taskId, intent`), `WORKS_ON` the task, and one `claim` event in a single write. Conflict → no claim is written, and one `conflict` event carries the paths (for the UI).
